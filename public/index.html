O que é

O TaskFlow é uma aplicação de gestão de tarefas em equipa, no estilo do Trello. Cada utilizador cria conta e faz login, vê os projetos onde é membro, e dentro de cada projeto organiza as tarefas num quadro com colunas (arrastando os cartões para mudar o estado). Cada tarefa pode ter subtarefas com percentagem de conclusão, e há ainda um relatório do projeto.

Funcionalidades

Contas e login

Registo e login, com a password guardada de forma segura (hash).

Projetos e equipas

Criar projetos e juntar/remover membros.

Quadro estilo Trello

Colunas por estado e arrastar para mudar de coluna.

Subtarefas

Checklist por tarefa com percentagem feita.

Relatórios

Total, concluídas e contagem por pessoa.

PWA + tema

Instalável no telemóvel, responsiva e com modo claro/escuro.

Como foi feito (técnicas)

  • Arquitetura MVC: rotas → controllers (com try/catch) → model (camada de persistência) → base de dados.
  • Base de dados PostgreSQL com prepared statements ($1) — protege contra injeção de SQL.
  • Passwords com hash (sha256) — nunca em texto simples.
  • Proteção contra XSS — o texto do utilizador é escapado antes de aparecer no ecrã.
  • Validação no servidor e autorização (só o criador apaga o projeto; o criador não pode ser removido).
  • PWA (manifest + service worker), design responsivo (mobile-first) e cuidados de acessibilidade.

Tecnologias

Node.js Express Cors pg PostgreSQL HTML Bootstrap JavaScript

⚙️ Estado da API

Aqui testamos todas as rotas e controllers a sério. O teste cria um utilizador, um projeto e uma tarefa de teste, faz todas as operações (criar, listar, editar, apagar) e no fim apaga tudo — por isso não fica nada na base de dados.

Server-Side Chronicles

Esta API saiu das aventuras da Grande Biblioteca — os desafios Server-Side Chronicles do formador Nuno Carapito. Cada capítulo deixou a sua marca no TaskFlow:

I 🏛️ O Labirinto da API — "planear e reconstruir o servidor usando REST". Foi onde desenhámos os nossos endpoints.
II 🧵 O Tecelão das rotas — "construir o teu nó com Node.js e Express". As nossas rotas na pasta routes/.
III 🕸️ O Ritual do Tecelão — "prova de resiliência e domínio de APIs REST". Os controllers com try/catch.
IV 🛡️ O Guardião dos Dados — "dominar a persistência para o conhecimento sobreviver". O nosso model + PostgreSQL.
V 🌀 A Fenda das Eras — "a prova final de sobrevivência temporal". As datas das tarefas (criação, prazos e atrasadas).
